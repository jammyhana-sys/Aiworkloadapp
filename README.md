# Demco Workload Timesheet V 1.0 (PWA)

โฟลเดอร์นี้คือแอปที่ติดตั้งบนมือถือได้ (Progressive Web App) — ไฟล์หลักคือ index.html

## วิธีใช้บนมือถือ
1. นำทั้งโฟลเดอร์ `pwa` ไปโฮสต์บนเว็บเซิร์ฟเวอร์ที่เป็น **https** (เช่น Azure Static Web Apps, SharePoint/IIS ของบริษัท)
   - อย่าโฮสต์โฟลเดอร์ `Workload Project` ทั้งโฟลเดอร์ เพราะมีไฟล์ Excel อื่นปะปนอยู่
2. เปิด URL บนมือถือ
   - iPhone (Safari): ปุ่มแชร์ > "เพิ่มลงในหน้าจอโฮม"
   - Android (Chrome): เมนู ⋮ > "ติดตั้งแอป" / "เพิ่มลงในหน้าจอหลัก"
3. การเข้าสู่ระบบใช้ Username/Password เท่านั้น (ไม่ใช้ Microsoft SSO) — Admin คนแรกสร้างบัญชีที่หน้า login ครั้งแรก

## ทดสอบบนเครื่อง
    python -m http.server 8765 --bind 127.0.0.1   (รันในโฟลเดอร์นี้) แล้วเปิด http://127.0.0.1:8765/

## หมายเหตุ
- Service worker จะทำงานเฉพาะบน https หรือ localhost ถ้าเปลี่ยนไฟล์แอปให้แก้เลข VER ใน sw.js เพื่อบังคับอัปเดตแคช
- ข้อมูลบันทึกงานเก็บในเครื่องมือถือของแต่ละคน (localStorage) ใช้ส่งออก Excel จากแท็บตั้งค่า (admin)

## ลืมรหัสผ่าน (ส่งอีเมลรีเซ็ต)
หน้าเว็บส่งอีเมลเองไม่ได้ ต้องตั้งค่า `CONFIG.mail` ใน index.html อย่างใดอย่างหนึ่ง:
- `provider:'emailjs'` — สมัคร emailjs.com ใส่ serviceId / templateId / publicKey (เทมเพลตใช้ {{to_email}} {{subject}} {{message}} {{reset_link}})
- `provider:'webhook'` — URL ของ Power Automate (HTTP request trigger) รับ JSON {to, subject, body, link} แล้วส่งผ่าน Outlook (ควรให้ Flow ตรวจว่า to ลงท้าย @demco.co.th)
- เว้นว่าง = ปิดฟีเจอร์ หน้า login จะบอกให้ติดต่อ Admin

ลิงก์รีเซ็ตใช้ได้ 30 นาที ครั้งเดียว และต้องเปิดบนอุปกรณ์เครื่องเดียวกับที่สร้างบัญชี (ข้อมูลเก็บในเบราว์เซอร์)

## ฐานข้อมูลกลาง Supabase (ทำให้ทุกคนใช้ข้อมูลชุดเดียวกัน)
แอปรองรับ 2 โหมด — เว้น `supabaseUrl/supabaseKey` ใน `index.html` ว่างไว้ = โหมดเก็บในเบราว์เซอร์ (เดิม) / ใส่ค่า = โหมดคลาวด์

1. สมัคร supabase.com → New project (แนะนำ region Singapore) → จดรหัสฐานข้อมูลไว้
2. SQL Editor → วางเนื้อหาไฟล์ `supabase_schema.sql` ทั้งไฟล์ → Run
3. เพิ่ม Admin คนแรก: แก้ค่าในคอมเมนต์ท้ายไฟล์ SQL (insert into employees ... role 'admin') แล้ว Run (ต้องใส่อีเมลบริษัทของ Admin)
4. Authentication → Providers → Email: **ปิด "Confirm email"** (สมัครแล้วเข้าได้ทันที) · Authentication → URL Configuration: ตั้ง Site URL และ Redirect URLs เป็น `https://jammyhana-sys.github.io/Aiworkloadapp/` (ใช้กับลิงก์ลืมรหัสผ่าน)
5. Project Settings → API: คัดลอก **Project URL** และ **anon public key** ใส่ใน `CONFIG.supabaseUrl` / `CONFIG.supabaseKey` ใน `index.html` (ห้ามใช้ service_role key) แล้วอัปโหลด `index.html` ขึ้น GitHub
6. เปิดแอป → "สมัครสมาชิก" ด้วยรหัสพนักงาน + อีเมลของ Admin → เข้าสู่ระบบได้ทันที → แท็บ "สมาชิก"/"ตั้งค่าข้อมูล" เพิ่มพนักงาน (ต้องมีอีเมล), โครงการ, assign
7. พนักงานแต่ละคนกด "สมัครสมาชิก" ด้วยรหัสพนักงาน + อีเมลที่ Admin เพิ่มไว้ (ต้องตรงทั้งคู่) → ระบบผูกบัญชีอัตโนมัติ แล้ว **Admin กด "อนุมัติ" ในแท็บสมาชิก** (ป้าย "สมาชิก (N)" แสดงจำนวนที่รออนุมัติ) ก่อนจึงเข้าใช้งานได้ · ฐานข้อมูลที่สร้างไว้แล้วให้รัน `supabase_update_signup.sql` แล้วตามด้วย `supabase_update_approval.sql` อย่างละหนึ่งครั้ง

หมายเหตุ: อีเมลยืนยัน/รีเซ็ตรหัสผ่านใช้ระบบอีเมลของ Supabase (ฟรีมีโควตาจำกัด ~ไม่กี่ฉบับ/ชั่วโมง — ถ้าใช้จริงแนะนำตั้ง Custom SMTP ใน Authentication → SMTP)
ความปลอดภัย: พนักงานเห็น/แก้ได้เฉพาะข้อมูลตัวเอง และเห็นเฉพาะโครงการที่ถูก assign (บังคับที่ฐานข้อมูลด้วย Row Level Security) · Admin จัดการได้ทั้งหมด


## สมัครสมาชิกแบบเปิด + Admin อนุมัติ
พนักงานสมัครเองได้โดยไม่ต้องมีรายชื่อก่อน (กรอกชื่อ รหัสพนักงาน อีเมล รหัสผ่าน) → สถานะ "รออนุมัติ" → Admin ตรวจสอบและกด อนุมัติ/ปฏิเสธ/แก้รหัส ในแท็บ สมาชิก ฐานข้อมูลที่สร้างไว้แล้วให้รัน `supabase_update_open_signup.sql` หนึ่งครั้ง (หลัง supabase_update_approval.sql)

## Dashboard
หน้าหลัก (บันทึกงาน) มีวงกลม progress 8 ชั่วโมง แยกสีตามประเภท: Cost และ SG&A N1–N8 พร้อมตารางสรุปชั่วโมง/เปอร์เซ็นต์ ตามวันที่ที่เลือก


## Dashboard รายวัน/สัปดาห์/เดือน/ไตรมาส/ปี
การ์ดวงกลมที่หน้าหลักเลือกช่วงเวลาได้ (วัน · สัปดาห์ จันทร์–อาทิตย์ · เดือน · ไตรมาสตามปีปฏิทิน · ปี) ใช้ปุ่ม ‹ › เลื่อนช่วง เป้าหมาย = วันทำการ × 8 ชม. (ไม่นับเสาร์-อาทิตย์/วันหยุด) แสดง Cost เทียบ SG&A เป็นเปอร์เซ็นต์ของชั่วโมงทำการที่กลางวงกลม และแยกชั่วโมงตามโครงการภายใน Cost

## ปรับชื่อและสีของประเภท
Admin แก้ที่ ตั้งค่าข้อมูล → ประเภท SG&A: ชื่อที่แสดงและสีของ Cost และ N1–N8 (รหัสยังเหมือนเดิม) โหมดคลาวด์เก็บใน Supabase ให้รัน `supabase_update_ui_settings.sql` หนึ่งครั้ง (ถ้ายังไม่รันแอปใช้งานได้ปกติ แต่ชื่อ/สีที่แก้จะไม่ถูกบันทึกบนเซิร์ฟเวอร์)


## ประวัติ/สรุป
เลือกช่วง วัน/สัปดาห์/เดือน/ไตรมาส/ปี พร้อม ‹ › เลื่อนช่วง · พนักงานทั่วไป: ของฉัน / ราย Project (เฉพาะรหัสที่ตนลงเวลา) · Admin: ทั้งหมด / รายฝ่าย / รายคน / ราย Project มีตารางสรุปรายคน (เทียบเป้า วันทำการ × 8 ชม.) รายการงานละเอียด และปุ่มส่งออก Excel/CSV ตามตัวกรอง
