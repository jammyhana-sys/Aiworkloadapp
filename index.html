ระยะเวลาอนุมัติเฉลี่ยต่อขั้น

ข้อมูลเก็บในเบราว์เซอร์เครื่องนี้ (localStorage) — ใช้ทดลองก่อนย้ายไประบบกลาง ในระบบจริง Cost ให้ PM/Admin เป็นผู้ assign และ SG&A ให้ฝ่ายขายเป็นผู้ assign

การ Assign งานให้พนักงาน

พนักงานจะเห็นเฉพาะรหัสที่ถูก assign ให้ (Cost = รหัสโครงการ, SG&A = Sales Contract No. / MT Project Code / Backlog Project Code) · ค้นหาในตารางด้านล่างแล้วกด ＋ Assign ที่แถว ระบบจะเลือกรหัสนั้นในฟอร์มให้ แล้วพิมพ์รหัสพนักงานได้เลย

ลำดับรหัสชื่อพนักงานที่ได้รับ assign

Budget ตั้งต้นโครงการ — นำเข้าจาก Excel และตรวจสอบตัวเลข

ไฟล์ .xlsx คอลัมน์ Project Code, Budget Hours (และ Budget Baht เฉพาะ Super Admin) — ช่องว่าง = ไม่แก้ยอดเดิม · ระบบ ตรวจก่อนบันทึก: ไม่พบรหัส, รหัสซ้ำ, ไม่ใช่ตัวเลข/ติดลบ, Budget ต่ำกว่ายอดที่ใช้ไปแล้ว, อัตราบาทต่อชั่วโมงผิดปกติ แล้วแสดงผลให้ตรวจ ก่อนกด "ยืนยันนำเข้า" · ปุ่ม "ตรวจสอบตัวเลข" เทียบยอดในหน้าจอกับฐานข้อมูล และหาข้อมูลที่ไม่สอดคล้อง

นำเข้าข้อมูลจาก IFS — 2 ชีต ทุกคอลัมน์ (Sale & Project · Project Admin)
