คุณกำลังเปิดในแอป LINE — ติดตั้งไอคอนจากหน้านี้ไม่ได้ ให้เปิดด้วยเบราว์เซอร์ของเครื่อง (Chrome / Safari) ก่อน
🌐 เปิดด้วยเบราว์เซอร์
ถ้ากดแล้วไม่เปิด: แตะ ⋮ / ⋯ มุมขวาบน แล้วเลือก "เปิดในเบราว์เซอร์"

✓ ติดตั้งไอคอนแล้ว

เปิดแอปจากไอคอนบนหน้าจอได้เลย
เปิดแอป

📱 Android (Chrome)

  1. แตะเมนู ⋮ มุมขวาบนของ Chrome
  2. เลือก ติดตั้งแอป หรือ เพิ่มลงในหน้าจอหลัก
  3. กด ติดตั้ง / เพิ่ม ไอคอนจะขึ้นที่หน้าจอ

🍎 iPhone / iPad (Safari)

  1. ต้องเปิดด้วย Safari เท่านั้น (ไม่ใช่ Chrome หรือ LINE)
  2. แตะปุ่ม แชร์ ⬆︎ (สี่เหลี่ยมมีลูกศรขึ้น) ที่แถบด้านล่าง
  3. เลื่อนลงแล้วเลือก เพิ่มไปยังหน้าจอโฮม
  4. กด เพิ่ม ที่มุมขวาบน

💻 คอมพิวเตอร์ / เบราว์เซอร์อื่น

Chrome / Edge: กดไอคอนติดตั้ง ⊕ ที่ช่องที่อยู่เว็บ หรือเมนู ⋮ → "ติดตั้งแอป" · เปิดหน้านี้บนมือถือเพื่อดูขั้นตอนของเครื่องนั้น
